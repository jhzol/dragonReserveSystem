# 首页加载修复与100MB持久缓存（本地待发布）

- 预算：100,000,000字节，仅专属 home-image-cache-v1 目录；LRU淘汰，当前进程已引用文件不淘汰，空间不足跳过保存。
- 下载成功并验证后异步copy，不移动临时文件、不压缩；下次进入先读取本地文件并验证可解码。
- URL（包括查询参数）为键。同URL自保存起有效期30天，读取不会续期；过期下次访问重新下载。当前JPEG Q88封面URL携带内容hash版本参数，换图必须更新URL/版本参数；同URL直接覆盖仍可能复用旧图。容量不足可提前LRU淘汰，不保证驻留30天。
- 缓存损坏、文件缺失、写满、API缺失、磁盘回调超时均降级。缓存检查最长等待1.5秒，超时走已有下载队列。
- 原生图片失败同步标记失效，避免恢复重读坏缓存。缓存命中没有伪造网络requestId。
- 实际曝光图片（含部分露出）先处理，初始观察批次最多等待120ms，无回调降级首屏排序。曝光任务未完成时不启动屏外任务；失败或15秒软超时解除门控，但软超时不释放任务槽。保持最多3个准备任务、隐藏不取消在途下载、有限恢复。滑动只更新待处理任务优先级，不取消在途下载。不是全局TCP连接数量保证。
